title: Referrals

---

The referral program lets you earn rewards when traders you refer open or close positions on Parquet. To participate as an affiliate, create a referral code and share your referral link. You earn an affiliate reward — a share of your referred traders' fees — applied automatically on every trade they make.

## Creating a referral code

1. Go to the [Referrals](https://parquet.exchange/referrals) page.
2. Enter a referral code: **4 to 8 characters**, letters and numbers only.
3. Submit the on-chain transaction to register the code.

Codes are case-insensitive — input is normalized to uppercase before registration. If the code is already taken, the transaction fails.

Once registered, your referral link is:

```
https://parquet.exchange/trade?ref=YOURCODE
```

## Sharing your code

Share your referral link on any platform. When a trader opens the link:

1. Parquet remembers your code on their device until they apply it.
2. The referral code is displayed in the interface so the trader can confirm it before applying.
3. The code is removed from the address bar once it's stored, so their bookmarks and shared links stay clean.

Your referral link works whether it points at the trade page or the referrals page.

## Applying a code

A referred trader applies your code either through the `?ref=` link or by entering it manually on the Referrals page. When you apply a code, it's linked to your wallet for good — you can only have one referrer, so double-check the code before you confirm.

- One applied referral per wallet. Once set, it stays the same.
- Validation rules for applying: max 32 characters, letters and numbers only.

From that point on, you earn an affiliate reward on every trade they make.

## Tiers

Today's Standard (default) tier: referrers earn **25%** of their referred traders' trading fees (claimable USDC, uncapped). The protocol admin can assign higher tiers along a four-step ladder — **25% / 30% / 35% / 40%** (tier 3 is the top/VIP rate). There is currently **no trader-side fee discount** — the full reward accrues to the referrer. Deeplinks auto-apply on first trade.

Affiliate reward (and any trader-side discount) percentages are determined by the on-chain tier configuration. Tiers can be updated by the protocol admin, so the numbers above can change — your tier determines the reward percentage you earn, and any discount your referred traders receive.

## Claiming rewards

Affiliate rewards accrue on every trade made by your referred traders. You can claim accumulated rewards at any time from the [Referrals](https://parquet.exchange/referrals) page.
