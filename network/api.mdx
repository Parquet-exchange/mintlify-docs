**Base URL:** `https://api.parquet.exchange`

The indexer is the public read API for on-chain perp activity and market-hours metadata. It ingests Anchor event logs and price updates, persists them to Postgres, and exposes a REST surface plus a `/ws` WebSocket for realtime broadcasts.

**Rate limit:** an in-process limit enforced by the indexer service; overflow returns `429`.

**CORS:** restricted to Parquet's official frontends. Server-to-server callers (no `Origin` header) are unaffected. For integration allowlisting, contact the team.

All timestamps in request params and response payloads are unix seconds unless explicitly stated otherwise. Exceptions, all called out in the per-route schemas below: ISO-8601 strings (`/market-hours.server_time`, queue-entry `*At` fields), stringified unix seconds (`/fees` and `/staking` `ts` fields), and millisecond epoch (`/points/leaderboard.updatedAt`).

**Field casing:** REST responses use camelCase, except `/market-hours` and `/halt-status`, which use snake_case for compatibility with the upstream clock shape and external monitoring tooling.

## Authentication

| Surface | Auth |
|---|---|
| Public REST (`/events`, `/ohlcv`, `/stats`, `/fees`, `/staking`, `/staking/history`, `/leaderboard`, `/points/*`, `/orderbook`, `/queue/*`, `/market-hours`, `/halt-status`, `/overview`, `/farm`, `/referral-stats`) | None |
| `/health`, `/health/live`, `/metrics` | Optional operator Bearer token — when configured, `/health` returns `401` without it and `/metrics` serves a reduced public payload |
| WebSocket `/ws` | None |

## GET /events

Returns Anchor events decoded from on-chain logs, newest first (descending `id`). Cursor-paginated.

**Query params:**

| Param | Type | Notes |
|---|---|---|
| `market` | string | Optional filter — canonical symbol or `GLOBAL` for cross-market events. |
| `type` | string | Optional event-name filter (`PositionOpened`, `PositionClosed`, etc.). |
| `owner` | string | Optional base58 wallet filter (matches `payload.owner`). |
| `limit` | number | Page size, 1–200 (default 50). |
| `before` | number | Return events with `id <` this value — pass the previous response's `cursor.before`. |
| `after` | number | Return events with `id >` this value. |

**Response:**

```typescript
type EventsResponse = {
  events: Array<{
    id: number;          // monotonic row id, the pagination cursor
    market: string;      // canonical symbol or "GLOBAL"
    type: string;        // event name
    slot: number;
    signature: string;
    ts: number;          // unix seconds
    payload: Record<string, unknown>;
  }>;
  cursor: { before: number } | null;  // pass as ?before= for the next (older) page
};
```

```bash
curl 'https://api.parquet.exchange/events?market=AAPL&type=PositionOpened&limit=50'
```

```json
{
  "events": [
    {
      "id": 312456,
      "market": "AAPL",
      "type": "PositionOpened",
      "slot": 312456789,
      "signature": "5Kp...",
      "ts": 1715731200,
      "payload": { "owner": "...", "sizeUsdc": "1000000000", "side": 0 }
    }
  ],
  "cursor": { "before": 312456 }
}
```

<Note>
Valid markets are the currently-listed symbols across all categories — US equities and ETFs, crypto, commodities, and forex (see [Markets](/markets) for the live list). `SPCX` is a SpaceX synthetic priced from a third-party reference feed, not SpaceX stock. Any unrecognized or inactive symbol returns `400` with the list of valid symbols, so the indexer response is the source of truth for what's accepted.
</Note>

<Note>
`id` is a monotonic row identifier assigned per successfully-decoded Anchor event. It is the pagination cursor (`?before=`); gaps are expected, since log lines that don't decode to a tracked event don't advance it.
</Note>

## GET /ohlcv

Time-windowed OHLCV candles built from indexed price rows.

**Query params:**

| Param | Type | Notes |
|---|---|---|
| `market` | string | Canonical symbol, required. |
| `resolution` | string | Candle width — one of `1m`, `5m`, `15m`, `1h`, `4h`, `1d`. |
| `from` | number | Window start, unix seconds. |
| `to` | number | Window end, unix seconds. |

The window is clamped server-side to 500 candles (`to` is truncated to `from + 500 × resolution`).

**Response:**

```typescript
type OhlcvResponse = {
  bars: Array<{
    time: number;    // bucket start, unix seconds
    open: number;    // raw price mantissa (divide by 100 for USD)
    high: number;
    low: number;
    close: number;
    volume: number;  // USDC base units summed over the bucket
  }>;
  truncatedToRetention: boolean; // true when `from` predates stored history
};
```

Empty buckets are forward-filled with flat, zero-volume candles so the series is continuous.

```bash
curl 'https://api.parquet.exchange/ohlcv?market=AAPL&resolution=1m&from=1715731200&to=1715734800'
```

<Warning>
`/ohlcv` returns **raw mantissa / 100** for price fields. The WebSocket price feed broadcasts **mantissa × 10^7** (1e9-normalized). Both yield USD but the divisors differ — see [WebSocket /ws](#websocket-ws) below. Do not mix formats.
</Warning>

## GET /staking

Global staking snapshot. APR, staker count, recent distributions. 60-second cache.

`apr` is USD-denominated (annualized staker rewards ÷ value of the staked PARQ, priced via Jupiter) and is **`null`** when it can't be computed — no PARQ price available, nothing staked, or an out-of-range result. Treat `null` as "—", not 0%. All token/USD amounts are 6-decimal integer strings.

```typescript
type StakingResponse = {
  apr: number | null;          // annualized %, USD basis; null when unpriceable / no stake
  weeklyRewards: string;       // USDC (6-dp) distributed to stakers over the trailing 7d
  totalStakers: number;
  totalDistributed: string;    // USDC (6-dp), all-time staker share
  totalStakedRaw: string;      // raw PARQ staked (6-dp) — the staked_vault balance
  protocolPriceUsd: number | null;  // live PARQ/USD used to value the stake
  recentDistributions: Array<{
    total: string;             // USDC (6-dp)
    stakerShare: string;
    treasuryShare: string;
    referralShare: string;
    ts: string;                // unix seconds
  }>;
};
```

## GET /leaderboard

Trader PnL aggregation over `PositionOpened` + `PositionClosed` events (single-pass; a wallet appears with either opens or closes). 60-second cache.

PnL is **net realized PnL** (`net_return − collateral`: price move minus fees, funding, borrowing, and price impact, bounded at −collateral) for closes after 2026-06-10; older closes report gross price-move PnL (the events predate the net fields). All close paths count — user closes, keeper TP/SL/limit fills, and liquidations (a liquidation books as a losing trade at −collateral). Volume sums both legs (open + close notional).

**Optional `owner` mode:** pass `owner=<base58 wallet pubkey>` to fetch **one wallet’s** stats with the **same** net-PnL/volume/trades/win-rate math as the board, plus **`rank`** (1-based among traders in the window for the requested `sort`, or `null` if the wallet has no activity) and **`totalRanked`**. Invalid pubkey → `400`. When `owner` is absent, the response is the ranked list (backward compatible).

**Query params:**

| Param | Type | Allowed | Default |
|---|---|---|---|
| `timeframe` | string | `24h`, `7d`, `30d`, `all` | `7d` |
| `sort` | string | `pnl`, `volume`, `trades`, `winRate` | `pnl` |
| `dir` | string | `asc`, `desc` | `desc` |
| `limit` | number | ≤ 100 (list mode only) | 100 |
| `offset` | number | ≥ 0 (list mode only) | 0 |
| `owner` | string | base58 Solana pubkey (optional) | — |

```typescript
type LeaderboardTrader = {
  rank: number;
  wallet: string;
  realizedPnl: number; // USDC, human units
  volume: number;
  trades: number;
  winRate: number; // 0..1
};

type LeaderboardListResponse = {
  traders: LeaderboardTrader[];
  timeframe: string;
  updatedAt: string;
};

// When ?owner= is set, the handler returns a single object (not `{ traders: [...] }`).
type LeaderboardOwnerResponse = {
  wallet: string;
  timeframe: string;
  sort: string;
  realizedPnl: number;
  volume: number;
  trades: number;
  winRate: number;
  rank: number | null;
  totalRanked: number;
  updatedAt: string;
};
```

## GET /points/leaderboard

Points engagement-currency leaderboard. Points are an off-chain currency accrued by the indexer from on-chain events — they are tethered to real economic flow (volume, realized PnL, liquidation, staking, referrals) and carry no rewards attachment. 60-second cache per `(view, season, limit, offset)`.

**Query params:**

| Param | Type | Allowed | Default |
|---|---|---|---|
| `view` | string | `lifetime`, `season` | `lifetime` |
| `season` | string | `YYYY-MM` (UTC calendar month) | current season |
| `limit` | number | ≤ 100 | 100 |
| `offset` | number | ≥ 0 | 0 |

**Response:**

```typescript
type PointsLeaderboardResponse = {
  updatedAt: number;                       // ms epoch the snapshot was built
  view: "lifetime" | "season";
  season: string | null;                   // "YYYY-MM" for season view, null for lifetime
  entries: Array<{
    rank: number;                          // 1-based, accounts for offset
    wallet: string;
    points: string;                        // decimal string
    breakdown: {
      volume: string;
      win: string;
      loss: string;
      liquidation: string;
      stake: string;
      referral: string;
    };                                     // per-category decimal strings
  }>;
};
```

```bash
curl 'https://api.parquet.exchange/points/leaderboard?view=season&season=2026-06&limit=50'
```

<Note>
All point values (`points` and every `breakdown` field) are **decimal strings**, not numbers — they preserve full `NUMERIC(30,6)` precision and may exceed JS safe-integer range. `liquidation` points are credited to the **liquidated** trader (the margin they lost), not the liquidator.
</Note>

## GET /market-hours

Proxy to an upstream market-calendar provider's clock plus the next-session edges from its calendar, cached server-side for **30 seconds**. Returns enough state for the frontend's `SessionBanner` to render the current pricing regime — `rth` / `blend` / `off_hours` — and the boundary at which the next regime starts. The banner polls this every 60 seconds.

```typescript
type MarketHoursResponse = {
  is_open: boolean;
  server_time: string; // ISO 8601 with US-Eastern offset (e.g. 2026-06-11T15:09:37-04:00)
  next_open: string;   // ISO 8601, US-Eastern offset
  next_close: string;  // ISO 8601, US-Eastern offset
  session: "rth" | "blend" | "off_hours";
  boundary_at: number; // unix seconds of the next session change
  now: number;         // unix seconds at request time (server clock)
};
```

```bash
curl 'https://api.parquet.exchange/market-hours'
```

`session` is the canonical signal for the pricing regime: `rth` means Pyth's on-chain `PriceUpdateV2` is the primary read for the free-RTH markets; `blend` means the relayer is in the 10-minute weighted blend at the RTH boundary; `off_hours` means pricing comes from an **off-exchange reference feed**. **Trading is live in all three regimes** — there is no longer an RTH-halt that reverts state-changing instructions. The `boundary_at` and `now` fields are computed off the server clock at request time, so even when the upstream clock body is cached stale-on-error, the session derivation stays current. (`is_open` is preserved for backwards compatibility; it equals `session === "rth"`.)

## GET /halt-status

Venue-wide emergency-halt state, read on demand from the chain (3-second cache; briefly serves the last good snapshot if the chain read fails).

```typescript
type HaltStatusResponse = {
  halt_mode: 0 | 1 | 2;                  // 0 = none, 1 = reduce-only, 2 = full
  halt_mode_label: "none" | "reduce-only" | "full";
  markets: Array<{ market: string; is_paused: boolean }>;
  now: number;                           // unix seconds (server clock)
};
```

```bash
curl 'https://api.parquet.exchange/halt-status'
```

`reduce-only` blocks new opens and orders but allows closes, cancels, and liquidations; `full` additionally freezes closes and liquidations. If the chain read fails past the stale window the route returns `502 { error: "halt status unavailable", stale_secs }` — treat that as unknown, not as halted.

## GET /oracle-coverage

Pyth primary-feed coverage ratio per market, bucketed by hour — the signal behind the price-integrity monitoring panel. A sustained `primary_ratio < 1.0` during regular trading hours means the on-chain read fell back from the primary to the secondary reference feed.

Query: `?market=<symbol>&hours=<1..168>` — both optional (default `hours=24`; omit `market` for every market).

```typescript
type OracleCoverageResponse = {
  rows: Array<{
    market: string;
    hour: string;          // ISO-8601 UTC, hour-truncated bucket start
    total: number;         // price reads in the bucket
    primary: number;       // reads served by the primary feed
    primary_ratio: number; // primary / total, in [0, 1]
  }>;
};
```

```bash
curl 'https://api.parquet.exchange/oracle-coverage?market=AAPL&hours=24'
```

An unknown `market` returns `400 { error: "invalid market" }`.

## GET /health/live

Liveness probe — orthogonal to `/health`'s readiness signal. Always returns `200` whenever the process is up and the DB is reachable, regardless of data age. Off-hours `/health` may return `503` (stale prices by design); external monitors that only treat `200` as healthy should poll `/health/live` instead so they don't page on every weekend / holiday session.

## WebSocket /ws

Realtime price and event broadcasts.

**Connection:** `wss://api.parquet.exchange/ws`

**Subscribing:** pass an initial market set on the URL — `wss://api.parquet.exchange/ws?markets=AAPL,TSLA` — or send `{"type":"subscribe","markets":["AAPL","TSLA"]}` after connecting. A connection with no subscriptions receives no `price` messages. There is no unsubscribe message; reconnect to change the set.

**Keepalive:** the server sends `{"type":"ping"}` every 30 seconds. Reply with `{"type":"pong"}` — clients that miss two consecutive pings are disconnected (~60–90 s).

The WebSocket stays connected across the RTH-to-off-hours transition; `price` messages keep arriving at the 1-second tick cadence, only the source set changes (Pyth-primary during RTH; the relayer-written off-hours reference outside RTH). A 10-minute blend window at each session boundary smooths the transition.

**Message shapes:**

The socket currently emits two server message types: `price` ticks and `ping` keepalives. Event broadcasts are planned but not yet emitted.

```typescript
type PriceMessage = {
  type: "price";
  market: string;
  // mantissa * 10^7 (1e9-normalized — divide by 1e9 for USD)
  price: string;
  timestamp: number;   // unix seconds
};
```

**Limits:** connection and message-rate limits apply. New connections are refused once the server-wide cap is reached, and clients that exceed the inbound message rate are closed with code `1008`.

<Warning>
**Price format split.** The WebSocket emits `mantissa × 10^7` (1e9-normalized — e.g. `114000000000` for $114.00). The REST `/ohlcv` endpoint returns raw mantissa / 100 (e.g. `11400` for the same price). Both produce USD when scaled correctly, but the divisors are different (`1e9` vs `100`). Pick the right one per data source.
</Warning>

## Rate limits and errors

| Status | Meaning |
|---|---|
| `400` | Invalid params — including an unknown market symbol (the `error` field lists the valid symbols) |
| `404` | Unknown route |
| `429` | Rate limit exceeded |
| `500` | Server-side decode or DB error |
| `503` | Indexer temporarily unavailable (stale data or internal failure) |

Rate limits are enforced per client; exceeding them returns `429`.
