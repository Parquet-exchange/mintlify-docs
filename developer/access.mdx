Parquet's developer references — the TypeScript SDK, the indexer REST/WebSocket API, and the protocol integration guides — are **available on request** rather than published openly.

If you're building on Parquet — an integration, a trading bot, an analytics product, or anything that talks to the on-chain programs or the indexer directly — reach out and we'll get you set up:

- **Telegram:** [@parquetexchange](https://t.me/parquetexchange)

Tell us what you're building and we'll share the SDK reference, the API surface, and the integration guides that fit.

<Note>
For verifying transactions, the canonical program IDs and USDC mints stay public on [Contracts](/network/contracts) — you never need access to confirm what you're signing against.
</Note>
